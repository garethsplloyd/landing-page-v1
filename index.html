Responsive Landing Page v1

19th October 2026

Welcome to my first attempt at a landing page. The main purpose was to feel more comfortable creating basic webpage layouts and arranging various elements. Moreover, this page serves as a holding place for my recipe page projects completed as part of The Odin Project Foundations course so far.

This page contains links to recipe web page projects 1 to 3.

This was also my first attempt at responsive design using media queries to accomodate resolutions smaller than 600px for mobile devices and tablets, and desktop devices larger than 600px.

Finally, hover and transition effects have been used on the cards and navigation menu buttons when viewed on a desktop browser.

The next step is to test mobile responsiveness at resolutions below 320px and refine navigation buttons and touch interactions for mobile devices.
